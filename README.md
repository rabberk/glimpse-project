# GLIMPSE

Project website for **GLIMPSE: Global–Local Indexing with Multi-Precision Spectral Encoding for Explorable Video World Models**.

Website: https://rabberk.github.io/glimpse-project/

This repository contains the static website, paper, and video demonstrations, not the training implementation or model weights. Full research code and model weights are planned for release after acceptance.

Serve the repository with any static web server. All media paths are relative, compatible with GitHub Pages project sites. Videos are generated results, with scene and method labels preserved from the demonstration. Qualitative examples are not quantitative benchmark results.

Authors: Zhufeng Xu, Henglei Lv, Bailin Deng, Yikang Ding, Xiaoqiang Liu, Guoxin Zhang, Hongbo Fu, Lin Gao. Corresponding author: Lin Gao.
